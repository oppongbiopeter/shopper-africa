# Shopper Africa

Instacart-style grocery marketplace for Ghana and Africa.

- Platform-owned customers (not merchant CRM / franchise territories)
- React Native app: Paystack + MoMo, personal shoppers, multi-vehicle delivery, optional drones
- Tips after delivery only
- Business docs and Ghana regulatory filing checklist in `business/`

## Layout

```
business/                 product, legal, ops docs
code/shopper-app/         React Native application
```

## Quick start

```bash
cd code/shopper-app
npm install --legacy-peer-deps
npm run test:core
```

See `business/DEVELOPER_HANDOFF.md` and `business/GHANA_FILING_CHECKLIST.md`.
